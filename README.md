Lab-Excercise-4-
A in class practice of Python- creating, viewing and searching tickets for sports events and live performances. Built during Systems Development module exercise to practice & OOP concepts.

What it does
Create sports or performance tickets and save them to JSON
View and search saved tickets
Handles sold-out tickets with a custom exception
Validates user input
Concepts used
Abstract base class + interface (ABC, abstractmethod)
Inheritance and polymorphism (SportsTicket and LivePerformanceTicket both extend Ticket)
Enums for sport/performance types
JSON read/write with a reusable file manager class
Custom exception handling
